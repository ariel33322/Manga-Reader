MANGA READER 1.0.0-5
=====================

Esta es la versión SOLO MANGA.

Incluye:
- Biblioteca.
- Portadas y metadatos.
- Continuar, Favoritos, Leyendo y Finalizados.
- Capítulos leídos/no leídos.
- Navegación anterior/siguiente.
- PDF, CBZ, ZIP e imágenes.
- Selector de discos.
- Icono oficial del gato.

INSTALACIÓN LIMPIA
------------------

1. Si tienes una versión anterior:

   sudo pacman -Rns manga-reader-local

2. En esta carpeta ejecuta:

   ./instalar.sh

3. Comprueba:

   pacman -Qi manga-reader-local

   Debe mostrar:
   Versión: 1.0.0-5

4. Abre Manga Reader desde el menú de aplicaciones.

Tus datos se guardan aparte en:

   ~/.local/share/manga-reader/

Desinstalar el programa NO borra esa biblioteca.
