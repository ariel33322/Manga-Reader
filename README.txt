Manga Reader es una aplicación de escritorio de código abierto para Linux, desarrollada en Python con PySide6/Qt6, orientada a la lectura y administración de bibliotecas de manga almacenadas localmente.

La aplicación permite organizar mangas mediante portadas, sinopsis, géneros, estados, favoritos y categorías de lectura, manteniendo un registro local de capítulos leídos y pendientes. Incluye un lector integrado con modos vertical, página individual y doble página, además de navegación entre capítulos y carga optimizada de imágenes.

Soporta la importación de capítulos desde carpetas de imágenes, JPG/JPEG, PNG, PDF, CBZ y ZIP, así como la vinculación de carpetas existentes. Las carpetas vinculadas pueden analizarse automáticamente al iniciar la aplicación para detectar e incorporar nuevos capítulos.

La biblioteca, configuración y estado de lectura se almacenan localmente, sin depender de servidores externos ni requerir conexión a Internet. Manga Reader está desarrollado principalmente para Arch Linux y distribuciones derivadas como CachyOS, Manjaro y EndeavourOS, e incluye PKGBUILD y scripts para facilitar su instalación y desinstalación.

Tecnologías: Python · PySide6 · Qt6
Plataforma: Linux
Formatos: JPG/JPEG · PNG · PDF · CBZ · ZIP
Almacenamiento: Biblioteca y configuración local
Licencia: Código abierto
Funcionamiento: Offline / sin servicios externos
